## Project Description
This Python program is a vending machine game set in a parallel universe. Players start with five space coins and can collect random imaginary products from three categories.

## Input
- Player's name
- Menu selection (1-5)

## Output
- Random imaginary products
- Special effects of each product
- Remaining space coins
- List of collected products

## Python Concepts Used
- Variables
- Input and output
- Conditional statements
- Loops
- Functions
- Lists and dictionaries
- Random values

## How to Run
1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Type: python3 myProgram.py
4. Enter your name.
5. Choose a menu option from 1 to 5.
6. Enter 5 to exit.
